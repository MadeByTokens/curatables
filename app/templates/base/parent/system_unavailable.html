Box

These pages manage the Curatables box itself: its Linux login, Wi-Fi, USB drives, updates and diagnostics. They only work on the ready-made Raspberry Pi image. On this computer, use its own settings instead.
For technical users

The pages talk to the root system helper, curatables-helper.service, over /run/curatables-helper/helper.sock. It is installed by the Pi image (scripts/apply-system.sh).
