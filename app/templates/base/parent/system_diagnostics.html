Getting help

The diagnostics report is a text file describing the box: the checks above, network and drive details, and recent logs. Passwords, Wi-Fi passwords and keys are removed, but it does name your networks and local addresses, so share it only with someone you trust to help.

Download the diagnostics report

If this page cannot be opened at all: turn the box off, put its SD card in any computer, and create an empty file named curatables-diagnose.txt on the card (the part the computer can open). Put the card back and turn the box on. A few minutes later, turn it off again: the card now holds curatables-diagnostics-report.txt.
