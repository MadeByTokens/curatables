Updates

yt-dlp is the engine that fetches videos. Sites like YouTube change often, so yt-dlp needs frequent updates to keep working. Updating happens in the background and the server restarts itself when it's done — you don't need the command line.

Video requests

Kids with Ask for new videos switched on (Kids → Edit) can search YouTube on their Find new page. The search runs on this server and the results go through these rules before the kid sees titles and pictures; nothing is downloaded until you add it from Video requests. YouTube's own SafeSearch is not applied, so keep the word list strict, or list the channels you trust.

Checked against the search words, titles, descriptions and channel names. A search containing one shows nothing.
Channel names exactly as YouTube shows them. Empty = any channel. Applies to channel search too.
0 = any length. Live streams are never shown.

Advanced Settings
Changes to port, host, log level, and session timeout require a server restart to take effect.

Server

TCP port the server listens on. Default: 8080.
0.0.0.0 = all interfaces, 127.0.0.1 = localhost only.
Log verbosity. Logs are written to the data directory under logs/.

Storage

How many videos download and convert at the same time. Keep 1 on a Raspberry Pi; extra videos wait in line. Applies once the current queue is empty.
Videos whose source file is bigger than this are not downloaded (protects the disk from very long streams). Default: 4 GB.
Refuse new downloads and uploads when free disk space would drop below this value. Default: 2 GB.
Absolute upper bound for a single uploaded video file. Default: 10 GB.
Per-upload ceiling for videos uploaded from kid profiles. Keeps kid uploads smaller than the parent ceiling. Default: 0.5 GB.

Anti-Bot

Some video sources (YouTube in particular) block automated requests. Browser impersonation usually works without any login. Cookies are a fallback if impersonation alone isn't enough, and other yt-dlp-supported sources generally don't need either.

Makes requests look like a real browser. Requires curl_cffi package.
Netscape-format cookies.txt. Only needed if impersonation alone doesn't work.
Reads cookies from a browser installed on this machine. Only for desktops, not headless servers.

Session

How long before the parent login session expires. Default: 24 hours.
